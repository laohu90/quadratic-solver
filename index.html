1. 判别式 Δ = b² - 4ac 的三大临界判定

  • 当 Δ > 0 时：方程有两个不相等的实数根，抛物线与 X 轴有两个交点。
  • 当 Δ = 0 时：方程有两个相等的实数根（重根），抛物线顶点恰好在 X 轴上。
  • 当 Δ < 0 时：初中实数范围内方程无解，抛物线与 X 轴无交点；在高中复数集内有一对共轭虚根。

2. 中考四大解法选择优先级

  • 缺少一次项 (b=0)：优先采用【直接开平方法】，如 x² = 9 ➔ x = ±3。
  • 缺少常数项 (c=0)：优先采用【提公因式法】，如 x(x - 5) = 0 ➔ x₁=0, x₂=5。
  • 常规题型优先十字相乘：能凑出十字相乘因式分解的题目，速度最快、不易算错。
  • 通用兜底万能钥匙：任何有解的题目，代入【公式法】求根公式百分之百解出。
