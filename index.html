1. 判别式 Δ = b² - 4ac 的三态判定

  • 当 Δ > 0 时：方程有两个不相等的实数根，抛物线与 X 轴有两个交点。
  • 当 Δ = 0 时：方程有两个相等的实数根（重根），抛物线与 X 轴相切。
  • 当 Δ < 0 时：在初中实数范围内方程无解，抛物线与 X 轴无交点（高中阶段有共轭复数解）。

2. 三种解题方法该如何挑选？

  • 首选因式分解法：如果能轻松凑出十字相乘（如乘积为 c，和为 b），算起来最快最准。
  • 其次公式法：所有题型的“通用万能钥匙”，只要将 a, b, c 代入求根公式绝不会出错。
  • 配方法：若二次项系数为 1 且一次项系数为偶数时最推荐，中考常考“配方求最值/顶点的证明题”。
