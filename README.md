## 📌 为什么本站全面超越普通竞品（对比 imathtool / 99cankao 等）

| 功能维度 | 传统网站 (如 imathtool、99cankao) | 本项目 (FormulaCalcKit) |
| :--- | :--- | :--- |
| **输入方式** | 只能逐个填写 a, b, c，无容错 | **支持直接粘贴任意整式方程**（如 \`2x² + 3x = 5\`、\`x^2 = 4x - 4\`），智能提取归一化 |
| **复数虚根支持** | 仅纯小数输出虚根，或完全不支持 | **初中中考模式（严谨实数判定）与高中复数模式（最简根式+虚根小数双输出）一键切换** |
| **推导步骤规范度** | 简略跳步，或中间带粗糙小数 | **人教版特级教师板书级推导**：判别式步骤、全分数配方法、十字相乘矩阵分析图解 |
| **二次函数性质** | 仅输出顶点或坐标 | **全景性质分析**：开口方向、对称轴方程、顶点坐标、极值、Y 轴截距、单调区间 |
| **逆向考点工具** | 无 | **内置“已知两根反求方程”**（逆用韦达定理），专攻中考压轴常考填空选择题 |
| **操作体验与架构** | 依赖第三方广告、阻塞式弹窗 | **现代微交互、轻量 Toast、SVG Favicon、黑白试卷免墨水打印排版、毫秒级响应** |

## 🚀 部署指南

### 方式一：上传到自建服务器 (Nginx / 宝塔面板)
1. 将本项目所有文件上传至网站根目录（如 `/www/wwwroot/formulacalckit.com`）；
2. 参考 `nginx.conf.example` 配置文件，内置 HTTP/2、Gzip 静态加速与安全响应头。

### 方式二：Vercel / Cloudflare Pages / GitHub Pages 一键上线
- 直接导入该 GitHub 仓库，无需配置任何构建命令，输出目录为根目录，一秒上线！
