> 🎯 **初中中考标准解法 · 公式法 · 配方法 · 十字相乘因式分解 · Δ判别式推导 · 二次函数抛物线图像可视化**  
> 🌐 **专为高频搜索流量与中考数学教辅打造的专业纯静态工具**

---

## 📌 项目核心亮点

1. **中考规范解题步骤**：
   - 拒绝单一枯燥的小数输出！像特级教师板书一样，清晰罗列 **① 识别系数 ➔ ② 判别式计算 ➔ ③ 代入公式法/配方法 ➔ ④ 约分解出两根**。
2. **多解法对照学习**：
   - **公式法**：中考万能通用解法，精确呈现最简二次根式（如 $\frac{-1 \pm \sqrt{3}}{2}$）；
   - **配方法**：严格按照人教版/苏教版/北师大版中考规范，全流程采用**最简分数**展现二次项系数化1、移项、配方 $(\left(x+\frac{b}{2a}\right)^2 = \frac{\Delta}{4a^2})$ 与开方步骤；
   - **十字相乘法**：独创**中考黑板级交叉相乘图解**，直观展现拆项乘积分析与 $(a_1x + c_1)(a_2x + c_2) = 0$；
   - **特殊秒杀法**：支持缺一次项直接开平方、缺常数项提取公因式秒杀技巧；
   - **韦达定理验算**：自动检验两根之和 $(x_1 + x_2 = -\frac{b}{a})$ 与两根之积 $(x_1 \cdot x_2 = \frac{c}{a})$。
3. **二次函数图像实时可视化**：
   - 动态 HTML5 Canvas 绘制对应抛物线 $y = ax^2 + bx + c$ 与对称轴；
   - 实时自适应缩放，高亮显示**抛物线顶点坐标**与 **X 轴交点（实数根位置）**；
   - 支持 $a=0$ 退化为一次函数直线 $y=bx+c$ 的无缝绘制与状态复位。
4. **极致极速与高可用架构**：
   - 纯静态零依赖，无需 Node.js 后端服务器，毫秒级冷启动；
   - 配备现代化轻量 Toast 提示、SVG Favicon、黑白试卷讲义打印适配；
   - 针对 Google / 百度搜索引擎深度定制 Schema.org 结构化数据卡片与 OpenGraph 社交标签。

## 🚀 部署指南

### 方式一：上传到自建服务器 (Nginx / 宝塔面板)
1. 将本项目所有文件上传至网站根目录（如 `/www/wwwroot/formulacalckit.com`）；
2. 参考 `nginx.conf.example` 配置文件，已内置 HTTP/2、Gzip 压缩与静态资源缓存加速规则。

### 方式二：Vercel / Cloudflare Pages / GitHub Pages 一键上线
- 直接导入该 GitHub 仓库，无需设置任何 Build Command，静态输出目录为根目录，一秒上线！
